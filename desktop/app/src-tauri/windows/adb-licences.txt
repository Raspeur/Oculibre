adb (Android Debug Bridge), shipped with Oculibre for phones connected by USB cable
=================================================================================

These files come unchanged from Google's Android SDK Platform-Tools 37.0.1 for Windows
(https://dl.google.com/android/repository/platform-tools_r37.0.1-win.zip):
adb.exe, AdbWinApi.dll, AdbWinUsbApi.dll, NOTICE.txt.

- adb, AdbWinApi and AdbWinUsbApi are part of the Android Open Source Project, licensed under the
  Apache License, Version 2.0. Copyright The Android Open Source Project.
- adb.exe also contains other open source libraries (BoringSSL, protobuf, zlib, zstd, LZ4, Brotli,
  mDNS…), under their own permissive licences, and libusb, licensed under the GNU Lesser General
  Public License, version 2.1. All their licence texts are in NOTICE.txt, as Google ships them.
- Source code: adb https://android.googlesource.com/platform/packages/modules/adb ;
  libusb https://android.googlesource.com/platform/external/libusb (the platform-tools-37.0.1
  tags of the Android Open Source Project). You may replace these files with another build of
  adb: Oculibre only runs adb.exe as a separate program.

Using the phone over USB through adb needs "USB debugging" on the phone, which gives the computer
wide access to it. This is temporary: a future version of Oculibre will connect over USB without
it (Android Open Accessory).
